# DesktopUmagFX - Scale Fix

Модифицированная и улучшенная версия приложения для электронных весов **DesktopUmagFX (4.1.0)**.

## Выполненные улучшения и исправления

### 1. Окно приложения
* **Отключён режим киоска (Kiosk Mode)**: приложение запускается в обычном окне Windows, которое можно перемещать, сворачивать и разворачивать.
* **Стандартная рамка Windows**: свернуть / развернуть / закрыть — системными кнопками окна. Дублирующие кнопки 🗕 🗖 ✕ в шапке убраны: самодельная ✕ закрывала программу через `System.exit` без корректного завершения работы с базой.
* **Запуск больше не сворачивает все окна Windows**: убран остаток киоск-режима, который при старте нажимал Win+D.

### 2. Простой интерфейс и тёмная тема (Dark Mode)
* **Единый стиль** (`styles/common.css`): одинаковые кнопки, поля ввода, таблицы, карточки и диалоги на всех экранах вместо шести разных вариантов.
* **Главный экран упрощён**: подсказки и кнопки действий собраны в одну компактную строку внизу, таблица занимает больше места; у пустой таблицы — понятная подсказка.
* **Экран входа**: форма по центру окна, показывается реальная версия программы (раньше была зашита «4.0.0-разработка»).
* **Экран товаров**: нормальная подсказка в поле поиска («Поиск по названию или штрихкоду»).
* **Исправлены опечатки**: «IP-адрес», «Штрихкод», «Доп. код» и др.
* **Тёмная тема переписана целиком** — исправлен «невидимый» текст (белое на белом и чёрное на тёмном):
  * переключатель (луна / солнце) в шапке и на экране входа; выбор **запоминается** между запусками;
  * тема одновременно применяется ко всем окнам и диалогам, включая открытые позже;
  * правила `dark.css` гарантированно перекрывают стили экранов (раньше стили экранов «побеждали» тёмную тему);
  * фон диалогов и цвета текста, которые программа задавала кодом, теперь тоже подстраиваются под тему;
  * отдельный светлый логотип для тёмной темы.

### 3. Исправление багов (Bug Fixes)
* **Таблица синхронизации**:
  * в пустых строках больше не остаются текст, иконки ошибок и удаления от прежних товаров;
  * у товара без штрихкода не показывается штрихкод другого товара и нет падения;
  * клик по пустой строке в колонке удаления больше не вызывает ошибку.
* **Кнопка темы**: вместо иконки на ней появлялся текст «u2600»; тема по-разному считалась на экране входа и на главном экране — теперь одно общее состояние.
* **Часы в шапке** могли отставать почти на минуту — теперь обновляются каждые 5 секунд.
* **Устранение `NullPointerException` при добавлении весов**:
  * проверка на `null` типа весов в `ScalesFactory.getScales(Scale)`;
  * валидация выбора типа весов в `AddScaleControl.onSave()` с информационным диалогом;
  * корректная обработка недоступности устройства в `AddScaleUseCase.add(Scale)`.
* **Ошибки разбора FXML (BOM и пустая строка перед `<?xml?>`)** устранены.
* **Сборка**: `repack_final.js` собирает JAR из всего содержимого `_extracted/` — изменённый файл больше не может «потеряться» из-за ручного списка; скрипты не зависят от расположения репозитория.

## Структура проекта

* `bin/` — скрипты запуска (`DesktopUmagFX.bat`, `ScalesCommunications.bat`) и локальная база данных HSQLDB.
* `lib/` — библиотеки зависимостей и основной исполняемый архив `DesktopUmagFX-4.1.0.jar`.
* `_extracted/` — извлечённые и модифицированные ресурсы (`layout/*.fxml`, `styles/*.css`, `image/`, пропатченные `.class` файлы).
* `patch_ui.js` — патчи байткода (тема, исправления таблиц, запуск); можно запускать повторно.
* `patch_senior.js` — исторические патчи байткода (уже применены к `_extracted/`).
* `repack_final.js` — пересборка `DesktopUmagFX-4.1.0.jar` из `_extracted/`.

## Сборка

Из корня репозитория, при закрытом приложении:

```bat
jre\bin\jjs.exe -cp lib\javassist-3.24.0-GA.jar patch_ui.js
jre\bin\jjs.exe repack_final.js
```

## Запуск приложения

```bat
cd bin
DesktopUmagFX.bat
```
