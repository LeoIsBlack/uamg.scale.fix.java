# DesktopUmagFX - Scale Fix

Модифицированная и улучшенная версия приложения для электронных весов **DesktopUmagFX (4.1.0)**.

## Выполненные улучшения и исправления

### 1. Управление окном и Kiosk Mode
* **Отключен режим киоска (Kiosk Mode)**: приложение теперь запускается в нормальном окне, которое можно свободно перемещать, сворачивать и разворачивать.
* **Добавлены кнопки управления в заголовок**:
  * 🗕 Свернуть в панель задач
  * 🗖 Развернуть / Восстановить окно
  * ✕ Закрыть приложение (с корректным завершением фоновых процессов)
* **Drag & Drop шапки**: возможность перетаскивать окно мышью за верхнюю панель и двойным кликом переключать режим «развёрнуто на весь экран».

### 2. Современный дизайн и Тёмная тема (Dark Mode)
* **Полный редизайн интерфейса**:
  * Современная цветовая палитра на основе Tailwind Slate/Emerald.
  * Новые стили бокового меню, карточек весов, таблиц и модальных окон.
  * Интерактивные hover-эффекты и скругления.
* **Полноценная тёмная тема**:
  * Переключатель темы (🌙 / ☀️) в шапке окна.
  * Устранены конфликтующие инлайн-стили (`style="..."`), блокировавшие CSS-классы.
  * Полное покрытие тёмной темы: таблицы, ячейки, заголовки, нижняя панель помощи, текстовые поля и диалоги.
  * Наследование тёмной темы всеми дочерними и модальными окнами (`StagedControl`).

### 3. Исправление багов (Bug Fixes)
* **Устранение `NullPointerException` при добавлении весов**:
  * Добавлена проверка на `null` типа весов в `ScalesFactory.getScales(Scale)`.
  * Добавлена валидация выбора типа весов в `AddScaleControl.onSave()` с отображением информационного диалога.
  * Добавлена корректная обработка недоступности устройства в `AddScaleUseCase.add(Scale)`.
* **Устранение ошибки парсинга FXML (BOM)**:
  * Очищены UTF-8 BOM маркеры в `layout/sync.fxml` и `layout/products.fxml`, приводившие к `Content is not allowed in prolog`.

## Структура проекта

* `bin/` — скрипты запуска (`DesktopUmagFX.bat`, `ScalesCommunications.bat`) и локальная база данных HSQLDB.
* `lib/` — библиотеки зависимостей и основной исполняемый архив `DesktopUmagFX-4.1.0.jar`.
* `_extracted/` — извлеченные и модифицированные ресурсы (`layout/*.fxml`, `styles/*.css`, пропатченные `.class` файлы).
* `patch_senior.js` — скрипт применения байткод-патчей через Javassist и Nashorn.
* `repack_final.js` — скрипт автоматической сборки и переупаковки `DesktopUmagFX-4.1.0.jar`.

## Запуск приложения

```bat
cd bin
DesktopUmagFX.bat
```
